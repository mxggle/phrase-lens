常见问题解答

我需要自己准备 API 密钥吗？›
是的 —— 可以使用你偏好的任意 AI 服务商的密钥。PhraseLens 不做任何中间商转售，费用由你直接支付给服务商，我们不收取一分钱。你也可以直接在本地运行 Ollama，完全免费、零网络开销。
这款应用是免费的吗？›
软件本身完全免费，并以 AGPL-3.0 协议开源。你唯一的支出是向服务商支付的模型 API 调用费用，以日常查词的轻量 Token 消耗计算，每次查询仅需几厘钱。
追问时会向模型发送哪些内容？›
你的新问题，以及该问题所针对的对话上下文：包含最初的查询请求、收到的结果，以及最多 8 轮经过修剪的历史对话。绝不会附带无关数据 —— 且整个对话串均保存在你的本地 Mac 上，与历史记录一同安放。
回答默认会以什么语言呈现？›
始终以你指定的目标语言呈现 —— 哪怕你选中的文本是另一种完全陌生的语言，且解析中大量引用了原文。原词、例句和引用会保留源语言；所有针对它们的讲解与分析均采用你的语言，且每条源语言例句都会紧跟地道翻译。
支持完全离线使用吗？›
完全支持。配合 Ollama 即可在离线环境下畅快运行。此外，截图 OCR 识别与 macOS 系统语音朗读无论使用何种服务商，均在端侧本地完成。
为什么需要辅助功能（Accessibility）权限？›
这是 macOS 系统中唯一能读取其他应用中划选文字并将修改后的文本直接替换回输入框的官方接口。正是借助这项能力，⌥F 划词查询与 ⌥W 就地重写才得以实现。若不授予该权限，主工作区、OCR 截图以及手动输入功能依然可以正常使用。
我的文本会被发送给你们吗？›
网络通信路径中根本不存在任何“中间服务器”。请求从你的 Mac 直接发往你配置的模型提供商。应用内没有任何数据分析、无崩溃日志上报，更没有可以接收数据的自建后端。
支持哪些 Mac 设备？›
支持运行 macOS 14 Sonoma 及更高版本的 Mac 设备，全面兼容 Apple 芯片（M系列）与 Intel 处理器。
